# Web Calculator 

A responsive calculator project built with HTML, CSS, and JavaScript. It is
suitable for a beginner web-development internship portfolio.

## Features

- Addition, subtraction, multiplication, and division
- Percentage calculations
- Decimal number support
- Clear and delete controls
- Division-by-zero error handling
- Keyboard support
- Automatic display resizing for long expressions
- Responsive layout for desktop and mobile screens

## Run the project

Open `index.html` in a browser. No installation or build command is required.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0` to `9` | Enter a number |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` | Calculate the result |
| `Backspace` | Delete the last digit |
| `Escape` | Clear the calculator |
